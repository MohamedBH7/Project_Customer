# Full-Stack Customer Management App

## Project Overview
This project is a full-stack Customer Management System with a React frontend, a Spring Boot backend, and a SQLite database. The application allows users to manage customers, including viewing, adding, editing, and deleting customers.

## Project Structure

The project is divided into two main parts:

- **/frontend**: The React frontend application
- **/backend**: The Spring Boot backend with SQLite database

### Folder Structure:
/frontend → React frontend application
<br/>
/backend → Spring Boot backend API + SQLite database

## Technologies Used:
- **Frontend**: React, Bootstrap
- **Backend**: Spring Boot
- **Database**: SQLite
- **UI Library**: Bootstrap
